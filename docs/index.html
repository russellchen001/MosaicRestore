AI video mosaic restoration

MosaicRestore is designed for restoring videos containing mosaic censorship or similar obscured regions using modern AI video restoration pipelines.

Local processing uses Apple Silicon and Apple MPS with Lada mosaic detection and BasicVSR++ restoration.

Built for long videos

  • Automatic chunking
  • Checkpoint and resume
  • Segment-level progress
  • Cancellation and retry
  • Validated final assembly

Local-first privacy

Local mode keeps video processing on the user's Mac. Cloud processing is optional and connects only to a host selected by the user.

Apple Silicon + NVIDIA

MosaicRestore supports Apple Silicon local execution and a provider-neutral NVIDIA cloud architecture based on Jasna, Lada, BasicVSR++ and TensorRT.

Important limitation

AI restoration generates a plausible reconstruction. It cannot recover factual original pixels that were permanently hidden by censorship.
